Key Design Decisions

✅ ALB in public subnet — ECS in private
✅ SSL terminates at ALB — HTTP internally
✅ ARM64 Graviton — 20% cheaper than x86
✅ NAT Gateway — private subnet internet access
✅ Secrets in AWS Secrets Manager — not env vars
✅ Stateless containers — data in RDS/Redis/S3
✅ Private subnet → NAT GW → IGW for outbound internet
